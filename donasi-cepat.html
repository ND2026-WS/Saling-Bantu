Jalur Cepat Berdonasi

Donasi Cepat — Tanpa Membuat Akun

Cukup isi nama dan nomor WhatsApp, pilih program yang ingin ditopang, transfer ke rekening yayasan, lalu kirim bukti transfer lewat WhatsApp admin. Setelah diverifikasi, donasimu otomatis masuk rekapan laporan.

Isi Data Donasi Cepat

Nama ini yang tercatat sebagai pemberi donasi (bisa disembunyikan di bawah).

Nama minimal 3 karakter.

Admin menghubungi nomor ini untuk verifikasi bukti transfer. Format 08xx / +62xx.

Nomor WhatsApp tidak valid — contoh benar: 081234567890.

Semua program di bawah sudah diverifikasi admin dan sedang menerima donasi.

Transfer ke rekening yayasan pada panel samping, lalu kirim buktinya via WhatsApp admin.

Nominal minimal Rp 10.000.

Tanpa daftar akun. Data donasimu langsung tercatat dan menunggu verifikasi admin.

Langkah Jalur Cepat

  1. Isi nama, nomor WhatsApp, pilih program & nominal.
  2. Klik Catat Donasi Saya — nomor kuitansi langsung terbit.
  3. Transfer sesuai nominal ke rekening di atas.
  4. Kirim bukti transfer lewat tombol WhatsApp yang muncul.
  5. Admin verifikasi — donasimu masuk rekapan otomatis.
Donasi Tercatat

Terima kasih! Niat baikmu sudah tercatat.

Sekarang transfer ke rekening yayasan di bawah, lalu kirim bukti transfernya ke admin lewat WhatsApp. Setelah admin memverifikasi, donasimu otomatis masuk rekapan & progres program.

Kirim Bukti Transfer via WhatsApp

Tombol WhatsApp membuka chat dengan admin yayasan (pesannya sudah terisi otomatis). Jika WhatsApp tidak terbuka, salin pesan lalu kirim manual ke nomor admin.
